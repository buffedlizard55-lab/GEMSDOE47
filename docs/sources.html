Geophysics — official data releases

sourcewhat it establishes
GeoDAWN airborne magnetics & radiometrics (USGS ScienceBase) Glen & Earney 2024, DOI 10.5066/P93LGLVQ; flown 2021-11 → 2022-11 over the NW Great Basin; joint USGS EarthMRI + DOE GTO effort; grid files downloadable (42 MB / 227 MB areas).
GeoDAWN on the DOE Geothermal Data Repository Mirror of the same release with a DOE citation — a fallback when ScienceBase is slow.
Magnetotelluric data, Gabbs Valley NV 2020 USGS release, DOI 10.5066/P9GZ9Z56: 59 wideband MT stations with impedance tensors and induction vectors, “the real induction vectors point towards strong conductors”. The closest public proxy for a direct geothermal indicator (conductive clay caps, fluid pathways) — and the most overlooked source in this competition, because it is a station network rather than a raster.
USGS Earthquake Hazards Program — faults Entry point to the seismicity and fault products used to sanity-check lineament hypotheses.
