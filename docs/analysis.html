1. The metric

The published metric, reimplemented in src/gems47_metric.py and validated against the organizer's own worked example (0.6027), reduces to

DTI = T / (0.2·T + 0.2·(M − C) + 0.8·N)        →        DTI = 5T / (T + FP + 4·N_g)

with T the truth mass covered, FP the emitted mass that misses, and N_g the true fault pixels. The kernel is k(d) = max(1 − d/3 px, 0), i.e. a 300 m credit radius at 100 m pixels. For a mask of non-overlapping dots T + FP = n, which gives the identity used throughout this project:

score = 5T / (n + 4·N_g)

The non-overlap condition is not an assumption here: this family's median nearest-neighbour spacing is 3.00 px against a kernel radius of 3 px, so neighbouring kernels barely touch.

5. Split conformal — the certified floor

Population: the flank-prune family. Calibration half = the three rungs with official scores. Selection half = the un-scored operating points B = 3 … 50. Nonconformity score = absolute leave-one-out error of the two-parameter model, refit on the other two rungs each time (Lei, G'Sell, Rinaldo, Tibshirani & Wasserman, JASA 2018).

held outrefit (T, Ng)predictionofficialresidual
B = 0(5,470; 15,200)0.260750.2600−0.00075
B = 1(5,223; 14,089)0.270480.2708+0.00032
B = 2(5,073; 13,368)0.278360.2778−0.00056

With n = 3 calibration points the largest certifiable miscoverage is α = 1/(n+1) = 0.25 (rank k = ⌈4·0.75⌉ = 3), giving q = 0.000755:

certified floor = 0.34912 − 0.000755 = 0.34837   at 75 % confidence
Confidence is 75 % and cannot be higher with the data we hold. A 90 % claim needs ⌈(n+1)·0.9⌉ ≤ n → n ≥ 9 live-scored rungs of this family; four rungs buy 80 %, nine buy 90 %. Exchangeability limitation: the calibration rungs retain 85–100 % of the network, the selected point retains 42 %; the guarantee is exact for the family and mechanism and holds under exchangeability at this depth — an assumption, not a theorem.

7. Limitations, in order of importance

  1. Long extrapolation. Live-validated over a 15 % prune; submitted at 58 %. The constancy of T beyond 2 px is the bet, and it is not validated.
  2. A falsified pessimistic branch exists. If T instead tracked structural coverage, B = 20 would land at ≈0.09–0.10 — far worse than the incumbent. We prefer constant T because the rivals fail the leave-one-out test and get the sign of Δ wrong, but the reader should know the branch exists.
  3. No working offline holdout. Both spatial proxies are noise (§2). No offline instrument in this project identifies a better operating point, and none is claimed.
  4. Sensitivity and breakeven. T −10 % → 0.3142; −20 % → 0.2793; −30 % → 0.2444. The submission beats the incumbent 0.2778 only while the retained dots keep ≥ 79.6 % of the assumed T, and beats the 0.3345 board maximum only at ≥ 95.8 %. Required retention falls with depth (99.3 % at B = 16, 93.0 % at B = 24, 89.4 % at B = 30), so a deeper prune is more robust to mild decay; B = 20 is chosen because the dots' density enrichment against the mapped-fault network crosses 1.00× at ≈20 px (2.20× at 0–1 px, 0.49× beyond 80 px).
  5. Best-of-board assumption. Free only if the leaderboard keeps the participant's best score. Verify before uploading.
  6. Score attribution is user-reported. The 0.2778 row is mapped to the GEMSDOE32 artifact by its owner's report, not by an artefact-authenticated receipt.
  7. Lineage disclosure. All 18,524 pixels are a subset of one published network, byte-unique against the 15 sibling rasters held locally (max Jaccard 0.4608). The operator is ours; the base is a published artifact used for learning. A fully independent emission is the top item of the next-session list.
