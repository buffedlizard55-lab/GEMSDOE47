What this repository contributes

1 · Exploratory owner-reported score/raster inversion

Twelve raster files are SHA-256 pinned, and their DTI pairings are owner-reported; there are no organizer receipts authenticating those links. LATI is a legacy name for an exploratory fit that treats the pairs as assumptions, not verified measurements of hidden labels. It is exact in T, uses a first-order approximation in Φ during fitting, has a 700× binned fast path, and includes diagnostic controls. H33-2-B2 is separate and appears only in conditional scenarios under an explicit assumed DTI.

→ the method and its limits

2 · Corrected metric algebra; score attribution unresolved

The inverse formula uses ρ = F/K; it is not the same ratio as F/T. At an illustrative, unverified F/K = 8.02, target 0.3195 requires 82.05 % weighted recall, not an impossible value. The public 0.2778 participant row is not authenticated to the H33 TIFF. Known masked pixels are excluded from penalty terms, so deleting predictions exactly on those pixels cannot improve DTI.

→ formula, regression test, and caveats

3 · Range-check audit; the original rejection remains unresolved

29 sibling GeoTIFFs were scanned. 12 of 12 -nan variants fail np.all((v>=0)&(v<=1)); 17 of 17 all-finite variants pass it. None of the 29 scanned files had a value outside [0, 1]. NaN is a demonstrated failure mode for the available -nan files, but the original rejected bytes are missing, so this does not establish the cause of that portal rejection.

→ the diagnosis

4 · H33 attribution is unresolved

A conditional LOO sensitivity changes sign between assumed H33 scores 0.2200 and 0.2400; that coarse-grid bracket is not an exact threshold. The public leaderboard provides no TIFF mapping, and the owner page marks H33-2-B2 unscored. The flank hypothesis is therefore unresolved, not falsified by the 0.2778 row.
