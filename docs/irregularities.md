## Portal-range error: safe conclusions only

The official task page requires a single-band 32-bit-float GeoTIFF on the competition grid, values in `[0,1]`, and null/NaN outside the data bounds. The reported error does **not** establish whether the rejected file had a genuine out-of-range prediction, a leaked nodata sentinel, a data-type/conversion issue, or an evaluator treatment of NaN. A future build must re-open the exact output bytes and report the metadata and value audit before offering it for download. If an alternative finite-zero-outside encoding is ever generated, it must be described as a compatibility fallback and checked against current official instructions; it must not silently replace the null-outside primary.
