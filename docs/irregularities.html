IR-47-001 The nodata value in training_features.tif is −3.4028234663852886e+38 — the float32 minimum — not NaN. np.isfinite() returns True for it. Any statistics, rank transform or model fitted without special-casing it treats −3.4e38 as a real measurement. All 19 bands are affected; 3,061 pixels inside the footprint carry it. A first pass at the band statistics produced mean = −inf for every band and an overflow warning. Every layer load tests v > SENTINEL with SENTINEL = −1e30. Recorded in evidence/training_band_stats.json as missing_in_fp. MEDIUM
IR-47-002 The reported 0.2778 attribution is contested. A sibling repository’s own records log attribution_conflict_site_says_unscored_official_board_has_unlinked_0.2778_row for h33-h33-2-b2-…-zeros. This single number is the only direct flank ablation in the whole 44-repository collection, and it decides the H47-2 verdict. If it is wrong, the strongest-looking hypothesis this project generated is alive again. Not resolved — it cannot be, without portal access. Instead of asserting a conclusion, scripts/flank_sensitivity.py reports the break-even: the flank is supported only if that file scored ≤ 0.2200. Manual review: open the competition leaderboard and check whether a 0.2778 row exists and which file it belongs to. HIGH
IR-47-003 sample_submission.tif is not an all-zero template. It contains 60,988 pixels at value 1, and every one of them coincides with labels == 1. Anyone who uploads the sample unchanged gets a submission consisting purely of masked catalogue pixels — mass that earns nothing. It also means the template cannot be used as a “blank” baseline for differencing. Recorded and asserted in src/gems47/grid.py::load_template. Not treated as a baseline anywhere. LOW
IR-47-004 The organiser’s reference solution does not optimise the leaderboard metric. drivendataorg/gems-prize-reference-solution trains a U-Net with smp.losses.TverskyLoss(alpha=0.2, beta=0.8, mode="binary") — a patch-level, unweighted, undistanced Tversky loss. The notebook contains no DTI scorer at all: no k(d) = max(1 − d/R, 0), no 300 m buffer, no global max-over-neighbours reduction. Patch-level Tversky and global distance-weighted Tversky have different optima. A model trained on the reference loss is not optimised for the score it is judged by. This is a real opportunity and also a trap for anyone who assumes the reference solution is score-aligned. Documented in knowledge/02_the_metric_algebra.md. The DTI here is implemented independently from the published formulas and verified against a literal O(N²) transcription and the organiser’s worked example. MEDIUM
IR-47-005 A blocked holdout on the given catalogue cannot be scored under the organiser’s masking rule. With mask_mode="zero", the holdout truth is the masked set, so g & evaluated is empty, K = 0 and DTI ≡ 0 for every candidate. A first run of that frame returned 0.0 for all four folds and all four arms. Sibling repositories report non-zero values on exactly this frame, so their scorers do not apply the mask the organiser says is applied. Any conclusion drawn from that holdout is measuring a different metric than the leaderboard’s. Frame F5 is scored unmasked and labelled as such, and is never used to select. Also recorded: this frame rewards catalogue skill, which is the opposite of the target skill, so it is structurally unfit for the purpose it has been used for. HIGH

IR-47-007 Optimizer’s curse measured at ≈0.30 DTI. A candidate built by maximising a fitted belief scored 0.6245 under that belief and 0.032–0.057 under four independent frames. Under cross-fitting the same candidate returned −0.0611 and −0.0450 against the incumbent. Any in-fold projection in this competition family — including a sibling repository’s “+0.0247 ± 0.0005, 12/12 draws positive” — is decorative. Several sibling repositories shipped candidates on the strength of such numbers. scripts/crossfit_validate.py implements the honest test (a-priori pool, selection inside each fold, out-of-fold scoring, paired against the incumbent). Its verdict gates shipping. Note the two folds selected different layers from the same pool — direct evidence the in-fold selection was fitting noise. HIGH
IR-47-008 A sibling repository’s truth model is self-referential. It draws hidden truth as π ~ exp(−d(H19-5)/1.85 px) — a scatter around the group’s own best field — then reports that a rule covering that field better wins by +0.0247 with 12/12 draws positive. The model cannot falsify the field it was built from. Every downstream decision scored against it inherits the circularity. Replaced by LATI, which is calibrated on returned scores for rasters that were not built from the model. Positive and negative controls are published alongside every screen. MEDIUM
IR-47-009 Two sibling downloads were verified defective. A “smooth-max-coverage” raster had 57.8 % of its 44,090 dots off the belief support it claimed to pack, and a catalogue-proxy DTI of 0.0163 against its own incumbent’s 0.1618. Root cause: blurring a 1-px binary ridge by σ = 1.85 px and then running max-coverage on the blur shifts the peak. A file like that scores near zero. It was quarantined upstream but is still publicly downloadable. The rule is not reproduced. Emission here enforces support confinement (a dot may only be placed where the belief field nominates a fault) and recomputes the marginal gain against credit already delivered, never against a static upper bound. MEDIUM
IR-47-010 An arithmetic error propagated through several sibling repositories. The marginal credit bar was written as α·s/(1 − α·s) = 0.0549 at s = 0.26. The correct value is α·s = 0.0520 — the published form is 5.5 % too high. Every emission threshold built on the wrong form stops 5.5 % too early, leaving earned credit on the table. Re-derived from first principles in metric.marginal_gain and asserted in tests/test_metric.py: breakeven_k(0.26) == 0.0520, and the general rule dT·(1/DTI − α) > α·dF reduces to k > α·DTI for dT = k, dF = 1 − k. MEDIUM
IR-47-011 Whether scoring is restricted to a public-chunk footprint is unresolved. No prior repository answers it, and no statement from the organiser was found. If the whole raster is scored but only public-chunk truth exists, mass in private chunks is pure false positive. That changes the optimal emission from “cover the footprint” to “cover the public chunks”, and it could account for part of the gap between 0.28 and 0.3262. Flagged, not assumed. The λ-probe design (H47-5) would settle it in three submissions. Manual review: ask in the forum, or read the rules page for a public/private split statement. HIGH
IR-47-012 The 1 m DEM was never used. The competition supplies links to 716 USGS 3DEP 1 m tiles. Only a sibling repository’s pre-derived 100 m LiDAR scarp rasters were reachable from this environment. Fault scarps are a metre-scale phenomenon. Averaging them to 100 m destroys the discriminating signal — consistent with every LiDAR-derived layer ranking poorly here (lidar_coh100, lidar_strike, lidar_valid among the worst of 72). The top of the leaderboard is almost certainly using the 1 m data directly. Flagged as the single largest untested lever. The derived 100 m rasters are used and their provenance is recorded, but no claim is made that they represent the 1 m signal. HIGH
IR-47-013 Six of the thirteen observations are nested thinnings of one field (d2.8 ⊂ h19-5, d1.5 ⊂ h19-5, d1.5 ⊂ tgc-v2; h19-4, h16-1 near-identical to h19-5 at 121k–124k dots). The effective sample size is well below thirteen. A three-equation solve on the nested triple alone returned condition number 3,136 and a collapsed solution — a documented dead end. Reported rather than hidden. All fits use leave-one-observation-out CV, and the cross-fitted test is stratified by reported DTI so each fold spans the range. MEDIUM
IR-47-014 Two bugs in this project’s own first pass, both caught by the review passes and both of which would have produced impossible numbers. (a) The first-order Φ ≈ ⟨q, a⟩ is an upper bound, not an estimate: it drove FPw to −47,502 and the predicted DTI to 1.6459. Measured over-estimate +0.8 % / +7.8 % / +87.4 % at q ~ 0.002 / 0.02 / 0.2. (b) The dense kernel shift filled out-of-grid positions with 0.0, which for 1 − q means certain hidden truth beyond every border; it inflated E[κ] along all four edges and made the dense and sparse paths disagree by 29 %. Both fixed. Φ now uses the exact Bernoulli ring-product expectation in the numerically stable form E[κ] = 1 − Σ(kₘ − kₘ₊₁)Qₘ, guaranteed in [0,1]; the fill is 1.0; dense and sparse agree to 1e-10; a hard assertion fails the build if FPw ever goes negative; and the exact expectation is validated against 600-draw Monte-Carlo at three densities (z = −0.58, +0.28, −0.17). FIXED
