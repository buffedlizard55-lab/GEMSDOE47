Promotion discipline

  1. Freeze a specific geological mechanism, field, controls, mask, spacing set, emission budget, holdout roles, and promotion criterion before scoring.
  2. Separate spacing/model selection from calibration. Use a correct finite-sample rank, name the prediction target, and state the exchangeability assumption. Spatial guards mitigate leakage; they do not prove exchangeability.
  3. Score DTI on all eligible truth-bearing evaluation pixels in each block, even when the detector's emission domain is narrower. Emission eligibility is not the metric scoring mask.
  4. Publish negative findings and corrected denominators. Do not reuse examined blocks as fresh confirmation.
  5. Only consider a slot if a candidate beats the current spatial-holdout best on a new defensible confirmation set and the user separately authorizes a portal attempt. Proxy DTI does not establish a score above the public 0.3774 leader.
