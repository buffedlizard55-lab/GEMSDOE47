Current H47-C1 package and metadata

The companion single-TIFF ZIP is 108,457 bytes (SHA-256 5a8eb75401daa713559297fc25198a3f31d6b7e7594118b111ec5160e7803b27); it contains the byte-identical C1 TIFF and no sidecar. The validation receipt and short portal note are metadata, not additional prediction rasters. C1 remains research-only and is not authorized for upload.

Grid and encoding details vary by artifact; each row’s hash, byte count, and status apply to that exact file. The H47-B NaN-outside single-scale file passes its strict local value/range check only with an explicit mask derived from the mirrored sample template; the feature-derived footprint fails. The paired all-finite diagnostic uses zeros outside and fails strict NaN-outside validation. It illustrates only a possible NaN-intolerant-check hazard. The original rejected bytes and parser receipt are unavailable, so the historical portal error cause and organizer acceptance are unknown.

Nothing here is recommended for a scored slot. The promotion gate and the reason each arm failed it are on the homepage and the executive summary.
