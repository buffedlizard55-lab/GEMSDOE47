# GEMSDOE47 GitHub Pages source

GitHub Pages serves this directory. The landing page leads with H50's NaN-outside TIFF for review; H50 is locally promoted on a documented spatially blocked public-proxy gate, but is **not organizer-accepted and not authorized for a competition slot**. H51 is a later research-only variant without a fresh H51-specific holdout. No upload or slot use is recorded. A local format check is not organizer acceptance.

The committed downloads are intentional so that exact artifact bytes are reviewable. This directory is not a submission-eligibility list. A valid GeoTIFF, a bounded-unique visible mask, and a local public-proxy result do not establish organizer acceptance, leaderboard performance, or a score-to-file mapping. Large restored inputs stay in ignored `.cache/`; see `data/README.md`.
