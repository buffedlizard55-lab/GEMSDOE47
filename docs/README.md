# GEMSDOE47 GitHub Pages source

GitHub Pages serves this directory. The C1 landing page is primary and keeps its one-click download first; the separate H47-QC artifact is linked from the landing page and executive summary for review. **Neither run is promoted. No competition slot is authorized; do not upload either TIFF.**

| Page / file | Contents |
|---|---|
| `index.html` | H47-C1 primary download and closed-gate finding, with the earlier H47-QC one-click research-only download and screen result alongside it |
| `executive-summary.html` | C1 summary, future-candidate-only submission steps, and H47-QC's separate failed-screen result |
| `h47qc-screen-20261006.json` | H47-QC blocked DTI sweep, calibrated-block order statistic, input hashes, and format audit |
| `h47qc-uniqueness-audit-20261006.json` | Bounded H47-QC comparison against the 55-repository / 334-exact-grid public inventory, plus a 12-TIFF same-repository post-merge comparison |
| `hypotheses-round2-20261006.md` | Four new hypotheses ranked before H47-QC implementation, with rationale, feasibility, and sources |
| `hypotheses.html` | Five earlier hypotheses, with the H33-2-B2 / 0.2778 attribution caveat |
| `method.html` | Exploratory proxy algebra, mapping caveats, numerical corrections, and conditional masking evidence |
| `evidence.html` | Evidence values with source-file references |
| `irregularities.html` | Current irregularity and limitation ledger |
| `prior-results.csv` | Owner-reported participant-score rows; raster associations are not organizer-authenticated |
| `prior-output-manifest.csv` | Current and retired TIFF outputs with SHA-256, byte-size, out-of-footprint convention, and status records |
| `downloads/` | C1 and historical/research-only GeoTIFFs, plus identification notes and single-TIFF ZIP |

The committed downloads are intentional: the artifact must be reachable from the live site with one click. This directory is not a submission-eligibility list. A valid GeoTIFF or unique visible mask does not establish scientific performance, organizer acceptance, or a score-to-file mapping. Large restored inputs stay in ignored `.cache/`; see `data/README.md`.
