If a future candidate passes: manual submission sequence

This is a future checklist, not permission to upload H47-B. Only a team member with authorized competition access should act. The official rules, live form labels, file limits, round schedule, and slot limits can change; recheck the official competition home and data/instructions page immediately before use.

  1. Confirm promotion first. Verify the candidate's preregistration, official-input provenance, spatial-block report, comparison to the current holdout best, controls, label coverage, and exact prediction hash. If any requirement fails or is missing, stop; do not spend a slot.
  2. Validate the final file. Use the competition's current sample-submission grid and instructions. Reopen the exact GeoTIFF bytes to confirm one band, expected CRS/shape/transform, finite in-footprint predictions in [0,1], and the required outside-footprint convention. Keep the validator receipt and SHA-256.
  3. Prepare identity and note. Give the promoted output a unique filename and a short factual note describing the method. Do not reuse either research filename or claim a public/leaderboard score that is not tied to this file by an organizer receipt.
  4. Sign in and start a new submission. Use the enrolled team's authorized DrivenData account; open the GEMS Prize competition and follow the current submission flow shown on the official page. Select the one-band `.tif` (or a `.zip` containing exactly one accepted TIFF if the current form requires that), enter the unique name and concise note if prompted, then submit manually.
  5. Verify the receipt. Wait for the portal's validation/scoring result. Save its submission ID, timestamp, displayed status/score and the exact uploaded file hash in the project record. A successful upload is not a holdout pass or a guarantee of final-round performance.

For the full checklist and format caveats, see How to submit a future promoted candidate. This repository never logs in, uploads a TIFF, monitors the board, or spends a slot automatically.
