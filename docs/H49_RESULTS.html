Published format requirement: FAIL

The exact TIFF read-back contains 12,279,160 finite cells, zero NaNs, no NoData tag, and a valid GDAL mask on every cell. The original build receipt records a 5,167,373-cell owner-mirror footprint; relative to that mask, 7,111,787 outside cells remain finite. The official format page requires values outside the data bounds to be null or NaN. The historical all-finite check did not test this condition.

Proxy results, not a private-score guarantee

The reported operating point is R7_scarp9_polarity, isotropic disk emitter, 2.8 px / 280 m spacing, density 7.37 per 1,000 scored pixels, and a 3 px / 300 m catalogue-flank buffer. The split-conformal arithmetic reports a nominal 90% lower-bound estimate of 0.03184 using 19 calibration blocks and order statistic k=18. It is conditional on block-score exchangeability, which is unverified; the input is public SGMC proxy data, not the hidden competition target.

The final operating rule was amended after repeated-split results were examined. The 400 re-splits reuse the same 39 blocks and are not an independent validation set. Formal coverage for the post-hoc amended selection process is not established. Do not call 0.03184 a certified, guaranteed, private-target, global, or map-wide performance floor.

Correct comparator attribution

The 0.2778 comparator is an owner-reported d2.8 reference raster. The relationship between that raster and the participant-reported score is unverified. It is not an authenticated leaderboard incumbent. H49's local comparison with its proxy score is not a leaderboard comparison and does not show that H49 beats the established spatially blocked holdout best.
