Signal construction

At offsets −6…6 along four grid directions, project elevation profiles and each template off an intercept and linear slope. Fit a signed erf step and an even Gaussian channel/ridge; retain normalized residual R², their difference, absolute height, along-strike continuity, width and gravity-normal agreement. Widths are 1 or 2 sampling steps: axial samples are 100 m apart, diagonal samples √2×100 m. The directional bank is coarse, not rotationally isometric.

step:    z(s) = a + b s + A erf(s / (√2 w))
channel: z(s) = a + b s + B exp(−s² / (2 w²))
competing physical explanations, not a fault-age estimate

Controlled models and splits

19 raw bands; raw + 7 ordinary terrain derivatives; raw + terrain + 7 profile descriptors (33 columns). Same HistGradientBoostingRegressor: 150 iterations, learning rate .06, 15 leaves, min leaf 100, L2=2, no early stopping, seed 470610. Up to 180,000 inverse-probability-weighted samples; 90,000 kernel-positive cap. No coordinates, catalogue-distance or old prediction-field features.

16×16 deterministic block lattice; 20-pixel guards per side. 41×41 minimum filter rejects invalid raw support. Target kernels see only catalogue labels in training cores. Spaced unit-dot quota matched across candidate, selection-only incumbent and seeded random control. Emit spacings 1.5 / 2.8 / 3.6 / 4.6 / 5.8 px.

Split conformal, accurately scoped

Compute five selection means μⱼ. Each calibration block produces rᵢ=maxⱼ(μⱼ−DTIᵢⱼ). Choose order statistic k=ceil((n+1)×.90), augment with +∞ if k>n, then Lⱼ=max(0,μⱼ−q). Select the largest floor, then selection mean, then larger spacing. A maximum over settings protects subsequent spacing choice if block score vectors are exchangeable; it is not a conditional geographic or private-score guarantee.

Lei et al., split-conformal theory establishes finite-sample marginal coverage under exchangeability. Adaptive leaderboard history is not an exchangeable calibration sample. A spatial guard removes local overlap, not geological domain shift.
