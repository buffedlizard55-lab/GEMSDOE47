1 · The problem with the previous instrument

A sibling repository’s truth model — the one every downstream decision in that family was scored against — draws hidden truth as π ~ exp(−d(H19-5)/1.85 px): a scatter around the group’s own best field. Any rule that covers that field better then wins by construction. Its own evidence file records exactly that: greedy_smoothfield beat that group's own best field by +0.0247 ± 0.0005 with 12/12 draws positive. The model cannot falsify the field it was built from, so the number carries no information.

LATI replaces that self-referential construction with an exploratory inversion. The repository contains twelve owner-reported raster/score pairs whose bytes are SHA-256 pinned; it has no organizer receipts authenticating the scores to those TIFFs. H33-2-B2 is an additional reference raster, but its association with the participant-level 0.2778 row is unverified. It is never counted as an authenticated thirteenth pair.

2 · What twelve owner-reported pairs and a conditional scenario can show

Write G for the hidden new-fault pixel set, K = |G|, and q(x) = P(x ∈ G) for its intensity. For a submission p with dot set D(p):

T(p)  = Σ_{g∈G} max_{x∈D(p)} k(d(x,g))  =  Σ_x q(x)·w_p(x),   w_p(x) = max_{y∈D(p)} k(d(x,y))    (L1)
Φ(p)  = Σ_{x∈D(p)} E_q[κ(x)],            κ(x) = max_{g∈G} k(d(x,g))
      = Σ_x q(x)·a_p(x),                 a_p(x) = Σ_{y∈D(p)} k(d(x,y))                            (L2)
F(p)  = S(p) − Φ(p)
DTI   = T / (α·(T + F) + β·K)              α = 0.2, β = 0.8, k(d) = max(1 − d/300 m, 0)

(L1) is exact. w_p depends only on p, so T is a linear functional of the unknown q. (L2) is first-order and is used only for the exploratory 12-row fits and the separate conditional 13-row scenario that assumes H33-2-B2 had DTI 0.2778; the emission path uses the exact Bernoulli expectation instead (§5).

Under the assumption that each owner-reported score is paired to its hash-pinned raster, that value contributes one non-linear equation in three modeled functionals of the same unknown. The exploratory set spans twelve raster families and masses from 37,654 to 343,816; adding H33 creates a hypothetical thirteenth row only under an explicit assumed DTI and the unverified score/file link. This sparse inversion ranks associations within those inputs; it is not tomography of authenticated ground truth or a fitted map of private labels.

3 · Exact reductions, verified to machine precision

FN_w = K − T          (the two published sums are term-wise complements)
FP_w = S − Φ          (k is decreasing, so max_g k(d(x,g)) is the kernel at the NEAREST truth pixel)

DTI   = T / (α·(T + S − Φ) + β·K)                        ← the design equation
1/DTI = α + α·(F/T) + β·(K/T)
DTI(λp) = λT / (λα(T+F) + βK)   ⇒   1/DTI is LINEAR in 1/λ  ← the λ-probe identity
d(DTI) > 0  ⇔  dT·(1/DTI − α) > α·dF                   ← the marginal rule
for dT = k, dF = 1 − k this reduces to   k > α·DTI       ← a dot pays iff k > 0.0520 at DTI 0.26

All five are asserted in tests/test_metric.py against a literal O(N²) transcription of the four published formulas and against the organiser’s own worked example (TPw 3.00, FPw 1.89, FNw 2.00 → 0.60).

4 · The model, and the parametrisation that made it identifiable

The first attempt used q(x) = expit(β₀ + Σβₘuₘ(x)). It failed: the optimiser ran coefficients to ±2,728, degenerating q into a hard indicator while reporting an implausible K, and a three-equation solve on the nested d2.8 ⊂ d1.5 ⊂ h19-5 family came back with condition number 3,136 and a collapsed solution. K and shape were confounded.

The fix is a softmax with the total mass as an explicit parameter:

q(x) = K · exp(Σₘ βₘ·uₘ(x)) / Σ_x exp(Σₘ βₘ·uₘ(x))
  • K is now identified by the diffuse probes — the r13-lattice and placeholder rasters, whose 300 m halos average the whole footprint and therefore measure mean density almost independently of shape;
  • the βₘ are identified by the concentrated probes;
  • β is shift-invariant, so no intercept has to be searched;
  • it cannot degenerate into a runaway hard threshold while still reporting a plausible K.

Every layer is reduced to a rank percentile (uint8, 0–255) over the evaluated pixel set first, which makes the fit scale-free and immune to the float32-min nodata sentinel −3.4028234663852886e+38 — a value np.isfinite does not catch. All 19 supplied bands contain it.

The binned fast path

T and K are exactly linear in q; Φ is replaced by the first-order linear approximation ⟨q, a_p⟩ during this exploratory fit. Since q depends on x only through the selected uₘ(x), these modeled functionals are determined by the joint histogram of the quantized selected features together with the per-cell sums of w_p and a_p. Aggregating onto that grid makes a model evaluation 0.015 ms instead of 210 ms — 700× faster — with a measured error of 1.1e-05 in DTI at 256 levels. That is what makes 65-layer screens, forward selection, leave-one-observation-out CV and 300 bootstrap replicates affordable on 2 vCPU; it does not remove the score/raster attribution uncertainty or validate hidden-target performance.

The permutation null tests whether these score/raster associations contain more than a concentration effect. A geometrically thin layer like dcat_band_0_1.5 produces a highly concentrated q automatically, and concentration alone can change fitted scores. A permutation preserves the layer’s exact multiset of rank values and tie structure while disrupting its spatial arrangement. All fourteen layers beat all 10 tested permutations in this exploratory fit. Ten draws are not a calibrated significance test, and the reported z-scores are descriptive comparisons with that finite sample. This is consistent with spatial structure in the owner-reported associations, but does not authenticate those associations, prove the LATI instrument/model valid, establish a geological cause, or validate private-target performance.

6 · Cross-fitting — a bias diagnostic, not a promotion gate

A candidate selected by maximizing a fitted objective and then scored by that same objective can look optimistically strong, potentially by construction. This cross-fit is designed to address two biases, but its small and unauthenticated observation set still limits interpretation:

  • B1 optimizer’s curse — the candidate is selected on the objective it is then judged by;
  • B2 pool-selection bias — the candidate layers were themselves ranked by LOO on the same rows. This recorded 13-row run includes H33-2-B2 at an assumed DTI of 0.2778; the score/file mapping remains unverified.

The bias diagnostic fixes a pool a priori from geology (twelve layers implied by “faults indicative of geothermal resources”: three geodetic strain-rate bands, two radiometric ratios, two thermal-discharge proximities, two seismicity densities, two magnetic bands, surface conductivity) — never from the fit; runs forward selection inside each fold; builds the candidate from fold A’s model and scores it with fold B’s, and vice versa; and scores the owner-reported d2.8 reference raster with the same out-of-fold model so the comparison is paired. The recorded 13-row fit includes H33-2-B2 at assumed DTI 0.2778; its score/file mapping is unverified, so the cross-fit is conditional.

7 · Two bugs the review passes caught

7a · Φ was an upper bound, not an estimate — and it drove FPw negative

The first-order Φ ≈ ⟨q, a_p⟩ replaces max by sum. That is valid while c(x) = Σ_y q(y)k(d(x,y)) ≪ 1, and it is an upper bound on the truth, never an estimate: κ(x) = max_g k(d(x,g)) ≤ 1, so Φ ≤ S always, whereas ⟨q, a_p⟩ is unbounded. On a concentrated belief field with a dense emission it exceeded S and the reported FPw went to −47,502, making the predicted DTI 1.6459 — impossible for the real metric. Measured over-estimate: +0.8 % at q ~ 0.002, +7.8 % at q ~ 0.02, +87.4 % at q ~ 0.2.

Replaced everywhere by the exact Bernoulli expectation over kernel rings: E[max] = Σⱼ kⱼ(Qⱼ₋₁ − Qⱼ) with Qⱼ = Π_{rings 1..j} Π_δ (1 − q(x+δ)). A hard assertion now fails the build if FPw ever goes negative.

7b · The stable form, and a boundary fill that meant “certain truth”

The ring-product form above subtracts nearly equal products. At q ~ 2e-3 it lost ~2e-4 per pixel to float64 cancellation, which summed over 150,000 dots and again pushed FPw to −28.2. Rewritten as

E[κ] = 1 − Σ_{m=1..6} (k_m − k_{m+1})·Q_m,     k_7 := 0

which only ever subtracts non-negative terms from 1, so E[κ] ∈ [0,1] by construction. Dense and sparse implementations now agree to 1e-10.

Separately, the dense shift filled out-of-grid positions with 0.0 — which, applied to 1 − q, means q = 1, i.e. certain hidden truth beyond every border. That inflated E[κ] along all four edges and made the dense and sparse paths disagree by 29 %. The fill is now 1.0 (q = 0 outside), and the two paths agree exactly.

8 · Masking — official clarification and limits of local comparisons

DrivenData staff states that known USGS/INGENIOUS pixels are excluded from evaluation and do not count toward penalty terms. The local mask_mode="zero" implementation removes masked predictions from the evaluated domain to represent that rule. The alternative "fp_only" mode is retained for audit/regression use only and is not the official interpretation.

The recovered 8GEMSDOE_Hedge-v2_submission.tif and gemsdoe-ens12-adopted-7f00890a.tif masks are byte-identical off the catalogue; Hedge-v2 adds 54,533 positive pixels on catalogue pixels. Their scores are both owner-reported as 0.1563, with no organizer receipts. This is descriptive and consistent with the official exclusion rule, but it is not a controlled causal ablation and does not establish any H33-specific score gain.

Under the official exclusion rule, predictions exactly on masked catalogue pixels cannot affect DTI; deleting them cannot improve DTI. Any effect of pruning nearby, unmasked pixels requires a controlled paired evaluation restricted to the unmasked evaluated domain.

A structural consequence worth stating. Under mask_mode="zero" a blocked holdout whose truth is the given catalogue cannot be scored at all: g & evaluated is empty, K = 0, and DTI ≡ 0 for every candidate. Some sibling repositories report non-zero local values on that frame, but those values are not organizer-authenticated evidence about the production scorer. F5 is therefore shown only as a contaminated diagnostic scored unmasked and is never selected on.

9 · Honest limits of LATI

  • Twelve owner-reported score/raster pairs cannot identify 59 coefficients. Any 13-row fit adds H33-2-B2 only as a conditional scenario under an unverified score/file mapping. The output is a ranking of layer families, not a map of G.
  • Six of the twelve owner-reported maps are nested thinnings or near-nested versions of one field, so the effective sample size is below twelve. A three-equation solve on the nested triple alone had condition number 3,136 and collapsed — a documented dead end.
  • The twelve score/raster associations are owner-reported transcriptions, not organizer-authenticated receipts. The H33 participant-score link is separately unverified. Treat the fits as exploratory.
  • K is a model-derived mass for the evaluated public footprint under the fitted assumptions, not a verified hidden-label mass. Whether official scoring is restricted to a public-chunk footprint or runs over the whole raster with only public-chunk truth remains unresolved.
  • The fit associates owner-reported score/raster pairs with proximity to some reference fields. It does not establish that hidden truth is near any particular field or identify a causal geology. The same-data proximity diagnostics are shown explicitly rather than presented as independent controls.
