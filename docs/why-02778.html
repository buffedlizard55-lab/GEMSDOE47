Exact DTI algebra

F = S − Φ
DTI = T / (α(T + F) + βK),   α = 0.2, β = 0.8

At fixed truth and domain, removing evaluated prediction mass can improve DTI only if avoided false-positive cost exceeds lost weighted truth credit. This is a possible mechanism, not an explanation of any unverified score. Deleting predictions exactly on masked pixels cannot by itself improve DTI.

Do not conflate ratios

With x=T/K and ρ=F/K, x=(αρ+β)/(1/DTI−α). With f=F/T, instead x=β/(1/DTI−α(1+f)). The denominators differ. An illustrative ρ=8.02 is not a verified participant ratio; the algebra does not establish that DTI 0.3195 is unreachable.

H47-SAF's tested sign change is bracketed only between assumed DTI 0.2200 and 0.2400—not an exact break-even. H47-GSA and dependent results remain hypothetical and research-only.
