What the reported 0.2778 does and does not establish

Attribution is unverified. The public leaderboard records scores by participant, not by TIFF hash. The H33-2-B2 raster is described as unscored in its owner-supplied material, and no organizer receipt links that TIFF to the participant-level 0.2778 row. Any analysis below that assumes the mapping is a hypothetical, conditional scenario—not an authenticated result.

The earlier long-form H33 analysis asserted that removing a catalogue-flank mask caused a score increase and used the claimed score-to-TIFF link as a “natural experiment.” That conclusion was not justified and is withdrawn. The exact set relationship between two owner-supplied raster byte sequences, if reproduced locally, is a geometric fact about those bytes only; it does not establish which file earned a leaderboard score or a causal score effect. Deleting predictions exactly on masked pixels cannot by itself improve DTI. Effects of pruning nearby evaluated pixels require a paired evaluation on the evaluated domain.

Exact DTI algebra, without a score-to-file assumption

For evaluated prediction mass S, weighted true credit T, false-positive mass F, evaluated truth count K, and Φ the maximum-kernel overlap term,

F = S − Φ
DTI = T / (α(T + F) + βK),   α = 0.2, β = 0.8

Removing evaluated prediction mass can help only when the avoided false-positive cost exceeds lost weighted truth credit. That identity describes a possible mechanism; it does not identify the mechanism behind any unverified participant score. A prediction on a pixel excluded from evaluation does not provide evidence that removing nearby evaluated pixels caused an improvement.

Keep the ratios distinct

Let x=T/K. If ρ=F/K, then

x = (αρ + β) / (1/DTI − α)

If instead f=F/T, then

x = β / (1/DTI − α(1 + f))

ρ and f have different denominators and are not interchangeable. Any chosen ratio must be labeled with its source and uncertainty. An illustrative ρ=8.02 is not an authenticated participant ratio. These equations do not show that DTI 0.3195 is unreachable; they are algebraic scenarios, not predictions of the hidden test.
