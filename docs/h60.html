Correction · 8 October 2026

H60: useful hypothesis,
invalid old scoring domain.

The older H60 family screen used each method's emission mask as DTI's valid scoring mask. That omitted truth pixels outside the method's domain, including false negatives. Its pooled summary also used total truth count instead of false-negative weight. Old values remain in place for historical audit and are not full-domain model rankings or metric assurance.

SCORING DOMAIN ≠ EMISSION DOMAIN

The emission mask says where a detector is allowed to place predictions. DTI must score all evaluated pixels in the guarded block. The corrected runner separates those masks, recomputes binary DTI across the full evaluated domain, and writes a new result under evidence/h60/corrected-domain/.
