Troubleshooting

"Predicted values must be in range [0, 1]"

This error can occur if the portal's range validator encounters NaN values that it doesn't recognize as nodata. Try the NaN-outside variant: Download NaN-outside variant (H60)

The NaN-outside variant writes NaN outside the competition footprint with nodata=nan. The all-finite variant writes 0.0 outside the footprint with no nodata tag.

File size

The all-finite variant is ~316 KB and the NaN-outside variant is ~369 KB. Both should upload quickly.

Which variant to use?

Try the all-finite variant first. If rejected, use the NaN-outside variant. Both have identical predictions inside the competition footprint.

About the Competition

The DOE GEMS Prize Challenge (DrivenData #306) asks participants to find geothermal-indicative faults in the GeoDAWN region of Nevada. The competition has two rounds:

  • Initial Round ($50,000): Scored against a private set of expert-labeled faults. Top 5 win $10K each.
  • Final Round ($250,000): Re-scored against an expanded label set built from expert review of all submissions. Top 5 win $100K/$70K/$40K/$25K/$15K.

See the official competition page.
